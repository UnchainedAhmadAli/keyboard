# Happy Keys 🎂

An installable keyboard app where every key press plays the next note of a tune
(Happy Birthday by default). English and Arabic layouts, works offline.

## Get a link to share
1. Merge this branch into `main`.
2. GitHub repo → Settings → Pages → Source: **GitHub Actions**.
3. Your link: `https://<username>.github.io/keyboard/`

## Install on a phone
- **Android (Chrome):** open the link → menu → *Install app* (or the Install button in the app).
- **iPhone (Safari):** open the link → Share → *Add to Home Screen*.

## Customize
- Songs: `SONGS` in `index.html` (list of notes).
- Layouts: `L` in `index.html` (add more languages the same way).
